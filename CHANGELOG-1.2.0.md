# Shutdown Tray 1.2.0 — локальная сборка

Основа: официальный тег v1.1.2, commit daa5a916651f7b08e2a5cf4f9fe0b8d8a32612a8.

- Окно настроек в стиле RoomSwitcher: 900×820 логических пикселей, плашки высотой 46, боковая колонка и поля шириной 244, системные шрифты, Mica, общие отступы и состояния элементов.
- Красная иконка приложения из утвержденного макета. Монохромные значки действий в трее сохранены.
- Вкладки «Основные» и «Действия в трее». Два независимых списка включенных действий: локальный и удаленный.
- У каждого списка свое главное действие. В текущем меню оно всегда первое и жирное, определяет иконку и двойной щелчок. Пункт «Отключиться» существует только в удаленном списке, может быть выключен и не добавляется повторно.
- Недоступные аппаратные действия видны в настройках с неактивным переключателем и подписью «Недоступно». Их нет в трее и среди вариантов главного действия.
- Горячая клавиша Ctrl+Alt+Shift+Q удалена.
- Подтверждение и обратный отсчет распространяются на отключение удаленного сеанса.
- Тема и язык применяются сразу при сохранении; окно остается открытым. При уходе с несохраненными изменениями предлагается сохранить, не сохранять или отменить уход. Подсказки в настройках не добавляются.
- Сохранены отложенные действия, быстрые интервалы, собственный интервал, дата/время, 30-секундное предупреждение, отмена и обработка пропуска во сне. Подменю использует список текущей сессии.
- Запланированное действие принадлежит тому списку, в котором было создано: изменение другого списка его не отменяет. Отключение планирования или самого действия в исходном списке отменяет таймер. Запланированное отключение RDP отменяется при возврате к локальной сессии.
- Старые настройки мигрируют автоматически: локальный набор сохраняется; удаленный получает прежний набор плюс «Отключиться». Выключенный прежний параметр UseRdpAsDefaultAction сохраняет обычное главное действие и в RDP.
- Сохранение настроек атомарное, предыдущая версия сохраняется в settings.json.bak.

Полный автономный архив содержит .NET и Windows App Runtime. Требуется распаковать всю папку; установка компонентов не нужна. GitHub не изменялся.

Проверка логики: dotnet run --project tests/Shutdown.PolicyTests.csproj -c Release.
Безопасная проверка интерфейса: Shutdown.exe --preview --preview-remote (или --preview-local). В этом режиме сохранение идет только в память, автозапуск и действия Windows отключены, используется отдельная копия приложения.
