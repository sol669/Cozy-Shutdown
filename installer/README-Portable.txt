Cozy Shutdown Portable 1.0.2
============================

Это стандартная компактная portable-версия.

Для запуска необходимы:
- Microsoft .NET 8 Runtime (x64)
- Microsoft Windows App Runtime 2.3 (x64)

Обычный установщик Cozy Shutdown проверяет компоненты и
автоматически загружает недостающие версии с серверов Microsoft.

Portable-версия ничего не устанавливает. Если необходимые компоненты
отсутствуют, используйте онлайн-установщик или установите их вручную.

Версия с пометкой Offline содержит официальные установщики этих
компонентов в папке Prerequisites. Запустите их только если программа
не открывается: сама папка приложения остаётся компактной.
