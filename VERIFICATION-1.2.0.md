# Проверка локальной сборки 1.2.0

- Сборка dotnet publish, Release, win-x64, .NET self-contained + Windows App SDK self-contained завершена успешно.
- Автотесты выполняют 196620 проверок независимости списков, порядка главного действия, отсутствия дубликатов, отсутствия отключения RDP в локальном меню, фильтрации недоступных действий и миграции старых настроек. Действия Windows тесты не вызывают.
- Приложение запускалось в отдельном режиме --preview --preview-remote; окно появилось в списке приложений, процесс отвечал, preview.log с ошибками не появился. Тестовая копия затем завершена; установленная версия не затрагивалась.
- Визуальное прокликивание, смена темы/языка через UI и hover не проверены автоматически: Computer Use вернул «Computer Use app approval timed out». Ограничение не обходилось.
- Выключение, перезапуск, сон, гибернация, блокировка и разрыв реального RDP не выполнялись. Их системные вызовы сохранены от 1.1.2, но реальное выполнение требует пользовательской проверки.
- build-local.ps1 читает каждый файл готового ZIP и проверяет SHA-256 относительно полного каталога сборки. SHA256SUMS.txt служит базой для последующих небольших обновлений.

Ручная проверка: обе страницы, настройки двух списков, выбор главных действий, тема/язык после «Сохранить», отказ от несохраненных изменений, недоступная гибернация, порядок трея в локальном/RDP контексте и отложенное действие с отменой.
